🚀 QUICK START
═══════════════════════════════════════════════════════════════════

1️⃣  READ: START_HERE.md or README_FIRST.md

2️⃣  CREATE EXCEL FILE (users.xlsx):
	┌────────────────────────────────────────┐
	│ Nama  │ Username │ Password │ IdRole   │
	├────────────────────────────────────────┤
	│ Ahmad │ ahmad123 │ pass123  │ 3        │
	│ Siti  │ siti456  │ pass456  │ 3        │
	└────────────────────────────────────────┘

3️⃣  LOGIN AS ADMIN:
	curl -X POST "https://localhost:5001/api/v1/auth/login" \
	  -H "Content-Type: application/json" \
	  -d '{"username":"admin","password":"password"}'

	→ Copy token from response

4️⃣  UPLOAD EXCEL:
	curl -X POST "https://localhost:5001/api/v1/auth/register-bulk-excel" \
	  -H "Authorization: Bearer YOUR_TOKEN" \
	  -F "file=@users.xlsx"

5️⃣  SUCCESS! Check database for new users.
